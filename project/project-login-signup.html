The Problem & Solution

THE PROBLEM

Traditional web authentication forms suffer from jarring full-page reloads, static error labels that only fire on submit, and lack of visual password security feedback. This causes high drop-off rates and encourages weak passwords among end-users.

THE SOLUTION

Fluid Tab State Machine & Real-Time Entropy Scoring

Designed a zero-reload, dual-panel authentication component. Uses hardware-accelerated transitions between Sign In and Sign Up tabs without layout disruption. Implements multi-heuristic entropy scoring that evaluates length, character variety, and numerical sequences instantaneously as the user types.

// Real-Time Password Entropy Evaluator
function calculatePasswordStrength(password) {
  let score = 0;
  if (!password) return { score: 0, label: 'Enter password' };

  // Heuristic Checks: Length, Uppercase, Numbers, Special Chars
  if (password.length >= 8) score++;
  if (/[A-Z]/.test(password)) score++;
  if (/[0-9]/.test(password)) score++;
  if (/[^A-Za-z0-9]/.test(password)) score++;

  const labels = ['Too weak', 'Weak', 'Fair', 'Good', 'Strong'];
  return {
    score: score,
    label: labels[score]
  };
}

Evaluates password complexity against length, case sensitivity, numbers, and symbols without external dependencies.

Key Challenges & Solutions

Challenge 01

Tab Switching Height Discrepancy

The Sign Up form contains more fields than the Sign In form. Switching tabs could cause sudden height jumps and content shifting on mobile screens.

Solution: Standardized form padding and used smooth CSS height containment transitions to guarantee visually stable switching.
Challenge 02

Security & Input Sanitization

Real-time input listeners can become vulnerable to XSS injection if unsanitized values are inserted directly into the DOM.

Solution: Enforced strict textContent assignments and avoided innerHTML mutations across all dynamic validation labels.
