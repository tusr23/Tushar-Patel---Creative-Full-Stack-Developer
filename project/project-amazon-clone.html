The Problem & Solution

THE PROBLEM

E-commerce storefronts frequently face cart synchronization desynchronization, layout shifts when rendering complex product catalogs, and accidental loss of active orders upon tab closure or network disconnection.

THE SOLUTION

Atomic Cart Store & LocalStorage State Machine

Engineered a unified event-driven cart state engine. Dispatches immutable order mutations, automatically recalculates subtotals, discounts, and item counters, and serializes state synchronously to browser storage for complete offline session persistence.

State Architecture & Code

cart-store.js ES6+ 
// Unified Event-Driven Cart Store
class CartStore {
  constructor() {
    this.items = JSON.parse(localStorage.getItem('amz_cart') || '[]');
  }

  addItem(product, qty = 1) {
    const index = this.items.findIndex(i => i.id === product.id);
    if (index > -1) {
      this.items[index].quantity += qty;
    } else {
      this.items.push({ ...product, quantity: qty });
    }
    this.sync();
  }

  getTotals() {
    return this.items.reduce((acc, item) => {
      acc.count += item.quantity;
      acc.subtotal += item.price * item.quantity;
      return acc;
    }, { count: 0, subtotal: 0 });
  }

  sync() {
    localStorage.setItem('amz_cart', JSON.stringify(this.items));
  }
}

Atomic State Reducers

Order additions and quantity modifications trigger atomic updates, preventing conflicting cart states.

Sub-Millisecond Math

Recalculates cart totals and item counts in microsecond execution time on pure vanilla JS.

Zero External Bundles

Delivers full e-commerce shopping interactivity without requiring hefty third-party libraries.

Key Challenges & Solutions

Challenge 01

Rapid Multi-Click Cart Flooding

Spamming the "Add to Cart" button could lead to out-of-order storage synchronization and UI counter flicker.

Solution: Debounced storage serialization and used synchronous in-memory state buffers before dispatching storage events.
Challenge 02

Product Card Layout Shifts

Varying title lengths and product badge tags caused jarring grid re-alignments during catalog filtering.

Solution: Implemented CSS Grid subgrids with fixed aspect ratios and line-clamped typography to maintain rock-solid layout stability.
